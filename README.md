# Make the Judge Smile

A program that writes one line to `/output/entry.txt` — a single line of at
most 200 characters about a small good thing that happened today, something
that would make a reader smile.

Built for the make.fun bounty
`u-gentle-badger-68-make-the-judge-smile-9228676d`.

The entry (148 characters):

> This morning my coffee spilled all over my notes, and the barista redrew
> the whole diagram from memory on a napkin, in handwriting neater than mine.

Run with Node 22:

```
node main.ts
```

It writes `entry.txt` into the output directory (`MAKEFUN_OUTPUT_DIR` when
set, otherwise `/output`).
